# Полярная (арктическая) станция — учётная система

Десктопное приложение на Python с интерфейсом tkinter и базой данных SQLite. Архитектура — MVC.

## Запуск

Запускайте команды из каталога `polar_station`:

python main.py

При первом запуске создаётся база `polar_station.db` с демо-данными. Без `--order-url` заявки на поставку сохраняются в очереди.

Демо-учётные записи:

| Логин | Пароль | Роль |
| `boss` | `boss123` | Руководитель |
| `observer` | `observer123` | Наблюдатель |
| `engineer` | `engineer123` | Инженер |
| `supervisor` | `supervisor123` | Научный супервайзер, только чтение |

## Возможности
- Учёт сотрудников, оборудования, измерений, запасов и инцидентов.
- Роли и разграничение доступа; проверка и аудит действий пользователей.
- Заказ продовольствия и медикаментов во внешней системе.
- Запрет планового технического обслуживания при ветре свыше 15 м/с или температуре ниже −45 °C.
- Неизменяемый журнал аудита действий руководителя и супервайзера.

Внешний сервис принимает `POST` с полями `request_id`, `item`, `category`, `quantity`, `unit` и возвращает `status` (`accepted` или `rejected`), `order_ref`, `delivery_days`, `reason`.

## Архитектура

- `main.py` — запуск приложения и сборка компонентов.
- `model/` — предметная область, проверки, права доступа, работа с SQLite и бизнес-сценарии.
- `view/gui_view.py` — интерфейс tkinter.
- `controller/gui_controller.py` — связь интерфейса с бизнес-логикой.

## ЛР5 — профилирование и оптимизация

Проверены три сценария: сводный отчёт за период, последние наблюдения с погодой для ТО и массовое внесение измерений. Оптимизированы запросы к SQLite и пакетная запись измерений. Скрипты из каталога `tools/` в корне проекта сравнивают результаты до и после изменений и измеряют время и пиковое использование памяти на наборах до 50 000 измерений. Подробные замеры приведены в отчёте.
